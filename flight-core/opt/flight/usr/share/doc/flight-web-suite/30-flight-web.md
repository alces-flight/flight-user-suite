# What is Flight Web Suite?

Flight Web Suite allows you to access Flight User Suite functionality through
your web browser.

Once your system administrator has enabled Flight Web Suite and provided you
with the access URL, you can log in using your cluster credentials.

Once logged in you can:

- Manage desktop sessions - start, connect, and terminate these as you would
  using `flight desktop` (if enabled)
- View `flight howto` guides

## Accessing Flight Web Suite

Contact your system administrator and ask them for the access URL to Flight
Web Suite.

Log in to Flight Web Suite using your cluster username and password.
